# air-more：无人机低空环境监测报告生成系统

实现《无人机环境与气象报告-方案比较.md》中**方案一（轻量报告服务）**：
A（巡测日报）+ B（异常快报）+ G（专项建议）三类报告，架构可扩展到 C–G。

A 类日报采用政府《环境空气质量研判日报》版式（参照内部版式参考件；公开快照不包含原始参考文档）：
三行红头报头（题名/期号/日期）+ 统计表（综合指数、名次、后三黄色/末位红色）
+ 贡献率饼图 + 四个固定节；定量图件参考灵嗅（Sniffer4D）无人机监测报告风格
（航迹着色图、指标曲线、分机库对比）。B/G 保持原有功能，报头与 A 统一。

> 本项目当前全部产物为**模拟数据演示，不用于业务决策**；机库为虚构，不指向真实主体。

## 架构

确定性流水线，不是 Agent 系统：

```
CSV 数据接入 → 质控 → 统计聚合 → 规则判定 → 结构化证据包
→ 出图 → 受限写作（模板/Ollama 可选）→ 数值一致性校验 → DOCX → PDF
```

LLM 只是"受限写作器"：输入是算好的结构化证据包，输出仅是叙述文字；
所有数值、单位、时间、位置由程序从证据包回填，并在渲染前逐处校验
（文本中每个"数值+单位"必须存在于证据包，证据编号必须存在），
校验不通过则不产出报告。模型不得自己生成数字。

```
airmore/
├── domain/      指标与单位定义、ppm↔μg/m³ 换算（GB 3095-2012 参比状态）、
│                演示综合指数与排名着色（composite.py）
├── ingest/      CSV 加载与 schema 校验（时区必须有，缺失剔除）
├── qc/          缺测/重复/时区/范围检查，输出质控记录；ox 标注"未参与计算"
├── stats/       按航次与时间窗聚合；航次等权平均避免高频航次支配
├── rules/       阈值筛查 + 持续性判定，输出内部状态（关注/建议复核/优先核查）
├── evidence/    结构化证据包 JSON（每条结论含证据编号、数值、来源）
├── charts/      航迹散点着色图、指标时间曲线、分机库对比、贡献率饼图
├── llm/         Ollama 客户端（可选）+ 确定性模板写作（默认）
├── validate/    报告文本数值与证据包一致性校验
├── render/      块驱动 DOCX 渲染（政府日报报头、排名着色表格），soffice 转 PDF
├── reports/     A/B/G 三个 builder（C–G 在此扩展）
├── pipeline.py  流水线编排
└── cli.py       命令行入口
```

## 数据与单位

- 污染物：pm1_0 / pm2_5 / pm10 / so2 / no2 / o3 单位 **μg/m³**；co 单位 **mg/m³**；ch4 单位 **ppm**。
- **ox 字段含义不明**：不参与任何计算，只在质控报告中标注"未参与计算"。
- 气象：温度 °C、相对湿度 %RH、气压 hPa、风速 m/s、风向 °（能见度 km、降水 mm 已定义，样例数据未包含）。
- ppm↔μg/m³ 换算按 GB 3095-2012 参比状态 298.15 K / 101.325 kPa
  （摩尔体积 ≈ 24.465 L/mol），见 `airmore/domain/units.py`，有单元测试。
- 筛查阈值在 `config/thresholds_demo.json`：参考 GB 3095-2012 二级浓度限值量级，
  文件与报告输出中均明确标注**"仅供演示，非正式标准判定"**；
  CH4 为演示用背景偏移阈值（>2.0 ppm），异常需现场核验。
- 内部状态"关注 / 建议复核 / 优先核查"与官方气象预警等级完全分开。

## A 类日报的演示综合指数（关键口径）

综合指数 = Σ(污染物浓度 ÷ GB 3095-2012 二级 24h 限值：
SO2 150、NO2 80、O3 160、PM10 150、PM2.5 75 μg/m³，CO 4 mg/m³），
见 `airmore/domain/composite.py`。**浓度为无人机巡测时段的航次等权均值，
非全天 24h 均值**（与固定站日报的关键差异，表注与证据 JSON 均写明）；
**仅供演示，非正式达标判定**。排名按综合指数升序，缺测排最后仍占名次；
排名后三黄色、末位红色（与参考日报一致）。当月累计表保留但填"/"，
注明"需连续观测数据累计"，不编造整月数据。预测节明确写"预测不可用"，
不编造 AQI。

## 运行

```bash
# 建环境（Python 3.13）
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

# 重新生成模拟数据（固定随机种子 42，可复算）
.venv/bin/python scripts/generate_sample_data.py

# 一键跑完整流水线（无人机巡测形态，默认）
.venv/bin/python -m airmore.cli generate --data data/sample --out out/ --reports A,B,G

# 测试
.venv/bin/python -m pytest tests/ -q
```

### 真实数据运行（固定网格点形态）

```bash
# 抓取 Open-Meteo 真实数据（郑州中原区网格点，CAMS/ERA5 模型数据）
.venv/bin/python scripts/fetch_openmeteo.py    # 输出 data/zhengzhou/ + SOURCES.md

# 固定网格点形态跑 A 类日报（周报效果：报告日期取最近完整日）
.venv/bin/python -m airmore.cli generate --data data/zhengzhou \
    --out out-zhengzhou --reports A --profile fixed_point --date 2026-09-06
```

`--profile fixed_point` 只做文案与图件参数化（`airmore/domain/profile.py`）：
声明改为 Open-Meteo 网格模型数据口径、"航次→自然日 / 机库→网格点 / 巡测→观测"、
航迹图换为单点位置图、持续性判定参数放宽到小时级（max_gap 90 分钟），
阈值仍标注"仅供演示"。B/G 报告措辞尚未适配固定网格点形态（避免不符数据的表述）。
`--date` 指定报告日期（默认数据起始日）。

输出（`out/` 下，共 9 个产物 + 图表）：

| 文件 | 报告 | 页数（本次运行） |
|---|---|---|
| `A_巡测日报.docx/.pdf/.json` | 无人机低空环境空气质量研判日报 | 3 |
| `B_异常快报.docx/.pdf/.json` | 污染物异常观测与复核建议 | 2 |
| `G_专项建议.docx/.pdf/.json` | 园区巡测与补测建议 | 3 |

PDF 由 soffice（LibreOffice）从 DOCX 真实转换，两版出自同一结构化 spec，事实一致。

## 模拟数据

`data/sample/`：2026-03-15 一个完整巡测日，4 个虚构机库（HANGAR-A..D）共 8 个航次，
基线水平 A 最高、D 最低（供排名演示）。埋入：S-A-2 航次 10:15–10:45 一段 PM2.5
连续偏高事件（PM10 同步抬升，A/B/G 共用）、S-B-1 缺测 3 条 pm2_5、S-A-3 缺测 1 条
humidity、S-A-1 重复行 3 条；S-A-2 为 10 秒高频采样（演示航次等权平均）。
固定随机种子，可随时复算。

## Ollama（可选，默认关闭）

默认使用确定性模板写作，离线可跑全流水线，**不会**调用任何 GPU 服务器。
仅当显式开启时才尝试 Ollama：

```bash
airmore.cli generate ... --use-ollama
# 或 AIRMORE_USE_OLLAMA=1；地址与模型走环境变量：
#   AIRMORE_OLLAMA_BASE_URL（默认 http://127.0.0.1:11434）
#   AIRMORE_OLLAMA_MODEL（默认 qwen3.5:9b）
```

任何调用失败都回退模板写作并在报告中注明"智能分析未完成"，不包装为"无风险"。

## 边界（未实现，属后续阶段）

- 预测（E）与气象融合（F）未实现：无连续历史、无外部预报接入（A 日报预测节如实标注）。
- 空间诊断（C）与过程复盘（D）未实现：需更多空间覆盖与可比历史。
- 业务筛查阈值与综合指数均为演示口径；未满足标准规定的测量方法和平均时段，
  不生成正式 AQI 或达标结论。
- 无观测区域不做插值、不生成全域热力图；未覆盖时段与区域不作推断。
- 报告为演示版，未接入真实机库数据、审核流程与版本管理；
  内部版式参考件仅作版式参照，公开快照不包含原始参考文档。
- 固定网格点形态（`--profile fixed_point`）仅适配了 A 类日报的文案与图件；
  B/G 报告仍为无人机巡测措辞，接入固定站点数据前需同样参数化。
- Open-Meteo 数据为 CAMS/ERA5 网格模型输出，未经地面监测站核实；
  跨午夜的连续事件按自然日统计单元切分（当前实现按 sortie_id 分组）。
