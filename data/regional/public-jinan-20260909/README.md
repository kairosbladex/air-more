# 济南及周边城市公开数据日报

本数据包于北京时间2026年9月9日11:15从网络获取，用于生成9月9日的3页日报。与东昌府区第244期仅有版式参考关系，未读取或复用该期统计数据。期号为本地报告编号，不是政府机关发布编号。

## 来源与统计口径

- 监测：中国环境监测总站全国城市空气质量实时发布平台 `https://air.cnemc.cn:18007/`。`city_daily.json` 为城市日报接口响应；8个 `city_<code>.json` 为逐日历史接口响应。完整URL、请求方法、取数时刻和原始响应SHA-256见 `sources.json`。
- 昨日：2026年9月8日的公开城市日监测结果；用日报接口与历史接口交叉核对日期、AQI、等级和首要污染物。这两个接口属于同一发布方，不能视为独立监测来源。
- 月累计：9月1日至8日，8个城市各8条完整日记录。按公开等级统计优良天数，优良率为优良天数除以8；PM2.5、PM10为8个日均值的算术平均；AQI范围为逐日最小值至最大值。报告显示一位小数，证据保留计算值。这些是公开日记录汇总，不是正式月度核定结果。
- 空气质量预报：生态环境部《9月上半月全国空气质量预报会商结果》，页面发布时间9月6日，内容有效期9月1日至15日。引用京津冀及周边地区9至10日、11至15日原文，不外推城市逐日AQI区间。
- 气象：Open-Meteo自动选择模型的济南网格预报，覆盖9月9日至13日。请求坐标36.65°N、117.12°E，返回网格36.66081°N、117.12975°E。湿度范围由小时值汇总；气温范围、最大风速和降水采用接口日值。模型起报时间未返回；11:15是取数时间。
- 工作建议：连续段落，先写昨日及本月事实，再写针对臭氧污染和静小风形势的检查建议；属于本报研判意见，不是已发布的行政管控指令。

所用来源没有提供本期正式综合指数、城市排名、园区监测和城市逐日AQI数值预报，因此不编造排名或贡献率饼图。图件采用济南、淄博真实逐日AQI，以及单独标注的气象模型数据。

## 复现

项目目录下执行，输出目录必须尚不存在：

```sh
.venv/bin/python scripts/public_jinan_report.py \
  --snapshot data/regional/public-jinan-20260909 \
  --out out-regional/public-jinan-reproduced
```

脚本为本期专用，固定报告日期、城市和预报原文校验条件；不是任意日期的在线日报服务。`--fetch` 仅允许写入新的快照目录。历史接口为滚动窗口，未来重新抓取未必还能取得本期全部日记录；本快照用于稳定复现。
