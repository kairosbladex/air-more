# 报告统计、标准依据与缺失处理

## 规则来源

本服务的 AQI 模块固定为 HJ633-2026+HJ663-2026+GB3095-2026/v1。
不是旧无人机报告中的演示综合指数，不改变旧CLI行为。

| 内容 | 原文位置 |
|---|---|
| 浓度修约、分段IAQI、AQI取最大分指数、向上取整 | HJ 633—2026 §4.2、表3 |
| O₃日最大8小时均值、缺测分支及首要污染物 | HJ 633—2026 §4.2、§4.3、§5.3 |
| 气体参比状态、颗粒物监测状态、有效采样要求 | GB 3095—2026 §3、§4.3、表4 |
| 每日17个O₃窗口，至少14个有效窗口及超限例外 | HJ 663—2026 §6.1.2、附录A.1 |
| 原始精度、统计与浓度修约 | HJ 663—2026 §6.3、表3；GB/T 8170 |
| 综合指数及权重，不能用AQI求和替代 | HJ 663—2026 附录C |

官方文件：
- https://www.mee.gov.cn/ywgz/fgbz/bz/bzwb/jcffbz/202602/W020260225366493492011.pdf
- https://www.mee.gov.cn/ywgz/fgbz/bz/bzwb/jcffbz/202602/W020260225383639187925.pdf
- https://www.mee.gov.cn/xxgk2018/xxgk/xxgk01/202602/W020260224700452407278.pdf

2026版AQI包括更新后的PM₂.₅日均分段值0/35/60/115/150/250/350/500，
PM₁₀为0/50/120/250/350/420/500/600。SO₂小时均值超过800时IAQI按200计；
O₃八小时均值超过800时IAQI按300计。不得从2012版表格复制旧例外逻辑。
浓度修约使用Decimal的ROUND_HALF_EVEN，指数使用ROUND_CEILING。
各项IAQI为零时，AQI展示取1以符合§4.1的1–500范围，分指数仍保留0。

有污染物缺测或无效时，先算有效分指数；其最大值>100时给出部分指标AQI并记录缺项，
否则AQI类别、级别等为NA。未开展监测且连续三年满足例外要求的豁免不自动启用。
这不是对正式发布权限、点位布设或监测方法资格的认定。

## 平台统计与标准评价分离

当前服务报告遵循 [已确认生成流程](air-report-approved-workflow.md)。展示浓度来自 Java 对应周期汇总表，趋势使用近15天/8周/12月完整时间轴，按精确载荷单位有效性屏蔽。以下原始巡测统计保留作内部证据和旧调用兼容，不能覆盖平台汇总。标准日 AQI 资格计算独立保留。当前报告的“综合指数”与占比依用户确认使用平台周期浓度及 HJ 633 分段算术，不以标准日 AQI 资格作为报告取数前提。

**巡测统计：** 同机库、同日、同指标先在每个有有效值的分钟内求均值，再对有数据分钟等权；
区间内对有数据日等权。不插值，不填零；不同单位无法统一时该汇总值缺失。
这避免高频采样直接压过低频时段，但仍仅代表实际采样，不能解释为完整日均或地区均值。
原始日序列留在内部证据中；不是HJ663的多年统计趋势检验。

**标准日AQI：** 必须显式配置已确认的固定点测量口径及单位、位置和采样区间含义。
同一天出现多个载荷或位置越界时，该机库的标准日AQI不可计算，不跨设备拼覆盖。
每条采样代表配置的固定长度区间均值（时间戳为区间起点），不凭相邻点距离推定持续采样。
第一版支持整除60秒的1至60秒采样区间，时间戳必须对齐。缺失区间不填补。
小时均值至少覆盖45分钟；相关日均至少20个有效小时。O₃每个8小时窗口至少6个有效小时，
窗口起始小时为0至16（结束于当天08:00至24:00）。有效窗口少于14个时，
仅当最大值严格超过已配置的一/二级O₃限值时保留统计结果。

`bo_task_air` 默认是轨迹数据，**没有固定点确认配置就不会自动计算标准AQI**。
已确定单位的巡测数值仍可显示；单位和测量状态缺口都记录在证据中。

## 测量确认配置

通过 AIRMORE_MEASUREMENT_PROFILES 指向服务维护方审核的JSON。
键是 `project_id:load_type:load_sn`。不能用请求参数打开固定点资格，也不能全库一键强制套单位。

```json
{
  "project-id:device-type:device-serial": {
    "mode": "fixed_point",
    "basis": "确认记录或设备协议版本",
    "hangar_id": "hangar-id",
    "method_confirmed": true,
    "interval_mean_confirmed": true,
    "sample_interval_seconds": 60,
    "location": {"lon": 0, "lat": 0, "tolerance_m": 10},
    "ozone_8h_limit": 160,
    "units": {
      "co": {"unit": "ppm", "confirmed": true, "state": "reference_298.15K_101.325kPa"},
      "pm2_5": {"unit": "μg/m³", "confirmed": true, "state": "ambient"}
    }
  }
}
```

示例位置是假值，不能投入业务使用。其余指标按已确认协议补齐。
气态污染物质量浓度统一到298.15K、101.325kPa参比状态；CO展示mg/m³，其余μg/m³。
ppm/ppb转换使用气体分子量和参比摩尔体积，不对颗粒物执行ppm转换。
原始质量浓度若未确认参比状态，不擅自使用数据库瞬时温压进行换算。

数据库 `bo_air_quality_index_project.index_unit` 按项目和登记载荷产品提供原始单位候选。
当前服务要求精确匹配 productNum 并解析启用字典；空缺、重复冲突、字典失效均无效。
显式测量确认配置不能填补当前服务的载荷单位缺项或覆盖冲突。移动采样可仅确认units，mode仍保留drone。

## 报告指数及比较期

当前服务入口 `report_index.py`（`report-platform-hj633-index/2`）按用户于 2026-09-21 确认的口径：**沿用 HJ 633 分段公式，用平台对应周期浓度计算，表头显示“综合指数”，占比按有效分指数归一化**。

当天/末日使用日汇总；周/月使用对应周期汇总，均直接代入表3日分段。六项原生单位经过已维护载荷校验后换算：ppm × 分子量 ÷ (8.314 × 298.15 ÷ 101.325) 得到 mg/m³，ppb 再除1000；SO₂、NO₂、O₃ 再乘1000换为 μg/m³，CO 保持 mg/m³。PM10、PM2.5 只支持质量单位换算。沿用现有分子量 SO₂64.07、NO₂46.01、CO28.01、O₃48.0。

浓度修约、分段、进位、最大值及 §5.3 缺项算术由现有 `aqi.calculate` 承载；固定点配置、原始记录覆盖、采样时段不阻断本业务计算。每期占比 = 该项分指数 / 该期有效分指数总和；零分母不绘制假比例。原始记录缺失但平台汇总与载荷单位有效时可计算。负值、非有限值、无单位、不兼容单位不参与分段计算；真实零保留。

内部结果明确记录 `qualified_daily_aqi=false`、O₃ 为平台周期均值、原生输入、换算值、修约值、分指数、无效原因、比例及整数排名。这并非 HJ 663 附录C的加权综合指数，也不将平台 O₃ 周期均值或月均值冒充合格标准日 AQI 的输入。独立标准日 AQI 仍按上文原有资格与时段规则计算。

旧 `CompositeRule`、`selection_index.py` 只为旧调用兼容保留，不参与当前报告排名或占比。

完整自然月比较上一个自然月；月累计对齐上月相同日，周累计对齐前一周；其他区间比较紧邻之前的等长区间。比较期用于成对占比图，排名表使用本期末日和本期。
只有两期相关指标每天都有可用巡测统计、单位一致时，才提供明确限定为巡测统计的差值。
所有日期和覆盖情况出现在证据及图件中，不把不完整比较期说成总体空气质量改善。
第一版历史数据统一用2026版规则回算，报告标识回算属性，不恢复当时发布口径。

## 模型与文档

模型通过Ollama `/api/chat`，`think=false`、结构化JSON、4096上下文、800输出token。
模型负责选择报告重点和组织三个章节；使用完整事实断言占位符，而不只约束数字。
例如一个被绑定的句子同时包含指标、时段、数值和采样范围，模型不能把合法数字重新搭配成污染原因。
每章从已核验事实/建议形成的候选段落中选取，后端回填中文正文。该方式是受限写作，
第一版没有开放任意自由因果分析。后续如扩大自由写作范围，必须增加独立语义验收。

模板直接保留用户Word的页面、样式、编号和原表格/图片组件，在原位置填入内容。
标题保持“空气质量研判报告”，不增加额外AQI表或页脚。五类表格分别为封面信息、
末日统计、区间统计、成对分项占比图、深色趋势图。预测图位置保留五天缺失图卡。
缺少分项口径时保留灰色圆形图位并标明待补齐，不绘制虚假彩色占比。

兼容性修正限于：浮动封面表框在页内定位；重复图表以原组件流式排版；固定行高改为最小行高；
新图按原表格列宽适配并清除旧截图裁剪；表头与首行保持相邻。源字体名称、字号、
样式、编号、页边距和列宽保留。PDF使用本机可用字体替代缺失的Windows字体，
因此跨Word/LibreOffice不能承诺逐像素相同或固定总页数。原始Word文件从未修改。
新模板版本为hangar-source-exact/v2。详见air-report-template-fidelity.md。

## 旧项目指标接口兼容（2026-09-15）

下述配置只保留在没有平台汇总目录的旧调用路径。当前服务统一使用 `registered-product-indicators/v1`，不会用该接口单位绕过实际载荷、产品和字典有效性检查。

启用 `AIRMORE_INDICATORS_PROJECTS` 后，单位来源改为用户指定的
`GET /airmonitoringNew/screen/indicators`，不再以 index_unit 缺失判断指标单位未知。
返回的 code/unit 是项目已启用指标清单，按编码映射并保留响应顺序。
未启用指标不会被测量确认配置重新启用。证据记录 `unit_source`、`project_indicators`
及对应配置哈希；凭证不写入证据。单位确认与标准评价采样资格仍分开处理。
